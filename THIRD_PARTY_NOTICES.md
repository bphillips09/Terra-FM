# Third-party software in terra_core

Terra FM's native engine (`libterra_core`) statically links the projects below.
Their sources are fetched at pinned versions by `tooling/fetch_third_party.sh`
(see that script for exact versions, checksums and local patches). Because
nrsc5 is GPL-3.0-or-later, Terra FM as a whole is distributed under
GPL-3.0-or-later; see `LICENSE`.

| Component | Version | License | Source |
|---|---|---|---|
| nrsc5 | 3.2.0 | GPL-3.0-or-later | https://github.com/theori-io/nrsc5 |
| FAAD2 (with nrsc5's HDC patch) | 2.11.2 | GPL-2.0-or-later | https://github.com/knik0/faad2 |
| librtlsdr (AlexandreRouma fork, Terra patch) | pinned commit | GPL-2.0-or-later | https://github.com/AlexandreRouma/rtl-sdr |
| libusb | 1.0.30 | LGPL-2.1-or-later | https://github.com/libusb/libusb |
| miniaudio | 0.11.25 | Public domain (Unlicense) or MIT-0 | https://github.com/mackron/miniaudio |

nrsc5 itself contains code under compatible licenses:

- Reed-Solomon decoder by Phil Karn, KA9Q (GPL).
- Viterbi decoder derived from Ettus Research code (GPL-3.0-or-later).
- `log.c` by rxi (MIT).
- `strndup.c` from gnulib (GPL).

Terra FM's own FFTW-compatible FFT shim and DSP code are GPL-3.0-or-later.

NRSC-5 decoding is provided by the open-source nrsc5 project.

## libusb (LGPL-2.1-or-later)

libusb is linked statically. To relink Terra FM against a modified libusb,
replace `third_party/libusb/` with your tree, keep the `.terra-stamp` file
from the fetched copy so the fetch script leaves it alone, and rebuild. The
complete corresponding source of Terra FM is available under the GPL.

## Natural Earth (base map)

`assets/maps/north_america.tbm` is generated by `tool/build_basemap.dart`
from Natural Earth 1:10m data (v5.1.2: land, lakes, country and state
borders, roads, populated places), clipped to North America, simplified,
and quantized. Natural Earth is in the public domain; credit is appreciated
and shown on the map ("Map: Natural Earth"). https://www.naturalearthdata.com
